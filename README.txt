光光老師的能源網站 2.0

部署到 GitHub Pages
1. 解壓縮，把資料夾內的全部檔案上傳至原 repository 的發布資料夾，覆蓋同名檔。
2. index.html 必須直接位於發布資料夾最外層；不要上傳 ZIP 本身。
3. GitHub Settings → Pages → Deploy from a branch → main → /(root) → Save。
4. 使用原本的 HTTPS 網址。所有路徑均為相對路徑，可部署在 repository 子路徑。

iPad
Safari 開啟 HTTPS 網址 → 分享 → 加入主畫面。
第一次連網開啟後，等待側欄顯示「題庫已可離線使用」。YouTube 影片和外部教材仍需網路。
安裝名稱、分頁標題、站內品牌均為「光光老師的能源網站」。

更新與學習紀錄
保留原 localStorage key energy112-training-v1 與原408題ID，既有紀錄與備份可繼續使用。
部署前可到原站「學習統計」匯出備份；不同網址、瀏覽器或主畫面App的儲存空間不一定共用，可用匯入方式移轉。
service-worker.js 取代原同名檔。若仍看到舊版，先連網開啟原網址，關閉該站全部分頁與主畫面App後再開啟，使等待中的更新啟用。
往後修改快取檔案時，請同時修改 service-worker.js 中 CACHE 的版本名稱。

功能
原408題與原四級、搜尋、練習、計時、成績、錯題及紀錄備份功能保留。
60道影片教材延伸題、六片內嵌播放器、即時解析、分片進度與錯題重練。
混合競賽預設各半抽題，另可只考原題或影片題；原級別篩選僅套用原題。
練習提交後即時解析；模擬競賽維持交卷後解析，未答計錯。

教材
SOURCES.html 為逐題來源與查核限制。video-bank.json 為可編輯題目資料備份。
網站直接載入 video-bank.js；若修改 JSON，須同步將內容寫成 const VIDEO_DATA=<JSON>; 至 JS。
未取得六片完整字幕，全60題明確標示為影片教材延伸題；尤其節能標章組依官方教材編写。
影片可能受發布者或地區限制，保留 YouTube 外開替代入口。
